# Swarm Maneuvering Directly from Point Clouds

Project website highlighting no mapping and fully decentralized swarm planning,
with simulation experiments, real-world formation flights and onboard recordings.

This is a static site. Publish the repository's `main` branch from `/ (root)`
in GitHub Settings → Pages. The entry point is `index.html`; `.nojekyll` keeps
the site as plain HTML, CSS, JavaScript and media without a build step.

The site includes 35 videos. The full project film is served directly at 1080p,
with English subtitles, narration and background music. Playback starts muted.
The external YouTube version is linked from the page.
